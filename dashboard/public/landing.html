The pod

Four things listen. Nothing else is shared.

A workspace is a bare pod with restartPolicy: Always — not a Deployment. An out-of-memory agent restarts its own container, keeps its pod IP and its attached volume, and takes nothing else down with it.

Coming alongside

Three stages, and the board narrates all of them.

A cold start pulls a multi-gigabyte image and clones a repository — far past any browser timeout. So the request returns immediately and the bootstrap reports itself as text, rather than a spinner that means nothing.

STAGE 01

Assign

Pick a repo and a branch. Berth derives a deterministic pod name, reuses the repo's volume if it has one, and answers 202 before the pod is anywhere near ready.

Moor

Attach

The terminal opens at its own URL. Close the tab, come back tomorrow, reattach — the tmux session, the checkout and the branch are all still there.

Health

Two probes, asking two different questions.

A workspace pod backs no Service, so a readiness failure is forever — one sat at 503 for eight hours without restarting. Liveness is the only lever that moves anything, which is exactly why it must never mean "the process is alive".

ProbeFails whenConsequence
/healthz Bootstrap unfinished, or the named agent session is goneMatched on the session name in /proc — never on a scrolling terminal pane The board shows the stage. Nothing restarts.
/livez The pod was ready once, the agent is gone, and three in-pane relaunches have been spentNever fails during bootstrap, so a slow clone is never shot The kubelet restarts the container, and the bootstrap re-proves itself.
auth-failed A login line in the pane, or credentials missing after 30 sThe one failure retyping a command cannot fix The ladder stops. The pod stays up carrying its message instead of crash-looping — and the terminal stays reachable, because that is where /login gets typed.

Storage

One volume per repo. Every branch lives on it.

  • Ending a session deletes the pod and keeps the volume, so the next one on that repo starts warm.
  • Branch checkouts sit side by side — switching branches costs a directory, not a clone.
  • ~/.claude is a subpath of the same volume, so credentials and history survive a restart.
  • Volumes are reclaimed only by the 30-day pruner, or by an explicit delete that refuses while a pod holds them.
/workspace/                # the repo's volume
  _home/claude/            # mounted at ~/.claude
  _home/claude.json        # ~/.claude.json links here
  main/                    # checkout
  feat/tekton-cache/       # checkout
  node_modules, build caches, and
  whatever you had not committed
